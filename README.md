## Dungeon Crawl II – JavaFX Roguelike Game Development

### Project Overview  
This is the second sprint of the Dungeon Crawl game development project, built with JavaFX. The goal was to expand and improve the existing roguelike game by adding new gameplay features, enhancing object-oriented design, and maintaining a growing codebase. The sprint focused on deepening understanding of OOP principles while making the game more dynamic and engaging.

### Objectives  
- Complete and refactor all mandatory tasks from Sprint 1  
- Add diverse NPCs with unique behaviors and roles  
- Introduce new item types with varied effects and interactions  
- Expand the game world with multiple thematic maps  
- Implement special abilities for both the player and NPCs  
- Maintain a clean, scalable codebase using OOP best practices

### Key Features Implemented  
- **NPC Expansion**:  
  - New enemy type with custom behavior  
  - Follower NPC that assist the player (cat)

- **Item System Enhancements**:  
  - Instant-effect items (healing potion)  
  - Usable items with triggered effects (sword)
  - Equippable items that modify player stats or appearance

- **Map System**:  
  - Three visually distinct levels   
  - Seamless map transitions with persistent player stats and inventory

- **Special Abilities**:  
  - Player ability triggered by key press
  - NPC abilities with varied effects

### Technical Highlights  
- Refactored codebase for better modularity and readability  
- Applied object-oriented design principles to support scalability  
- Used inheritance and polymorphism to manage NPC and item behavior  
- Ensured game state persistence across levels
